# Week 2 design plan (16-21 Nov 2026)

## What week 1 looked like
Four text-only cards on one template: header, left-aligned serif headline, Arabic line, small paragraph, footer. Clean and on-brand, but every post read the same in the grid, and nothing on the canvas showed the idea.

## What changes this week
1. One drawn object per post that carries the idea, built in HTML/SVG in the brand palette (no stock photos, no AI people):
   - P1 Google profile: an abstract map with a single glowing pin and a floating profile checklist card.
   - P2 carousel: each tip slide shows a miniature post (the format we recommend) as an object on the page.
   - P3 reel: a review card that gets a calm reply typed under it, then moves to a private message with a lock.
   - P4 bilingual: a mirrored composition. English left, Arabic right, the brand arc bridging them.
2. Hierarchy: one dominant line per canvas (headline at 92-110px), Arabic given equal weight, supporting text capped at two lines each language, more empty space around the object.
3. Colour: light/dark alternate across the week (P1 dark, carousel cover dark + light interiors, P4 light). Cyan used only on the object, never on a single headline word.
4. Reel: captions moved inside the safe zone (bottom edge above y=1440; week 1 sat at 1480), on-screen English hook from the first frame, SFX on each reveal.
5. Data-led timing: IG/FB at the Metricool peaks (10:00 weekdays, 18:00 for the reel), LinkedIn at its own 11:00 peak instead of sharing the Instagram time.

## Type
Cormorant Garamond 500 for English display, Noto Naskh Arabic 700 for Arabic display, Manrope / IBM Plex Sans Arabic for UI text inside the drawn objects (so the objects look like interfaces, not posters).

## Self-critique checklist for every render
Orphan Arabic word, text touching the object, footer crowding, unequal side margins, anything that looks like a template filler.
